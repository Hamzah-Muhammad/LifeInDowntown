# Life In Downtown

A third-person RPG set in real downtown Toronto, built in Unity 6 (HDRP).

You play Tarik, who lives alone in a 1-bedroom condo downtown, seen through his chest-mounted camera. The city is generated from real OpenStreetMap data, so the streets, blocks, building heights and shop locations match the real downtown.

## Status

Early development. Milestone 1 is walking a few real blocks around Yonge-Dundas at night. See [docs/DESIGN.md](docs/DESIGN.md).

## Requirements

- Unity **6000.3.26f1** (Unity 6.3 LTS) with HDRP 17.3
- Git LFS (`git lfs install`) for textures and models
- Python 3.11+ for the map tools in `Tools/osm/`

## Open the project

1. Clone with LFS: `git lfs install`, then `git clone https://github.com/Hamzah-Muhammad/LifeInDowntown`
2. Open the folder in Unity Hub with editor 6000.3.26f1.
